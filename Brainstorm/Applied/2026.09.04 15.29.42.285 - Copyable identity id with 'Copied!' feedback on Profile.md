# Copyable identity id with 'Copied!' feedback on Profile

Kategori: ux | Efor: M | Rank: 10

## Ne
MainProject/UI/Pages/Profile.razor: the `<p class="profile-identity">@(AuthService.CurrentIdentity?.PublicId)</p>` line renders the ML-DSA public key as plain word-break:break-all text (confirmed in ProfileCss.razor, line 36) with no way to interact with it. Add an IconButton (MainProject/UI/Elements/Buttons/IconButton.razor, already exists) next to the id that calls IJSRuntime.InvokeVoidAsync("navigator.clipboard.writeText", ...) - note this would be the first IJSRuntime interop call anywhere in the repo, not a reuse of an existing pattern, since CoreModal/CoreInput/CoreCard do not currently use IJSRuntime - and briefly shows a CoreChip (MainProject/UI/Elements/Core/CoreChip.razor, already exists, takes a Text parameter) reading 'Copied!' for ~1.5s using AppMeasures.Duration tokens before hiding again. Styling addition goes in MainProject/UI/Pages/ProfileCss.razor.

## Neden
The PublicId is the single piece of data the Profile page exists to show, and right now it is a long key a user can only try to manually select out of wrapped, unreadable break-all text - there is no practical way to actually use or share your own identity. That is a real, verified dead end in the app's core feature (identity), not a cosmetic gap, and a one-tap copy with a small confirmation fixes it directly.
