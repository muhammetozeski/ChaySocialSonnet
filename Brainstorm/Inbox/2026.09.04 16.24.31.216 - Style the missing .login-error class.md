# Style the missing .login-error class

Kategori: ux | Efor: S | Rank: 12

## Ne
In MainProject/UI/Pages/LoginCss.razor, add a `.login-error` rule (color: AppColors.TextDanger or similar, font-size via AppMeasures.Font, margin/padding via AppMeasures.Space) to style the `<p class="login-error">` that Login.razor renders on a failed HandleContinue server verification (line 33: `_errorMessage` shown when ApiClient.SignInAsync returns false).

## Neden
Verified by reading both files: Login.razor emits `<p class="login-error">@_errorMessage</p>` but LoginCss.razor's `<style>` block (lines 1-55) has no `.login-error` rule at all - only `.login-screen`, `.login-card`, `.login-title`, `.login-subtitle`, `.login-identity-box`, `.login-identity-label`, `.login-identity-value`. So the one user-facing failure message in the whole auth flow ("Could not verify your identity with the server...") currently renders as plain unstyled black text, indistinguishable from normal copy, with no error affordance.
