# Post detail page with notification deep links

Kategori: ux | Efor: M | Rank: 20

## Ne
Add GET /api/posts/{postId} to PostEndpoints.cs, resolving via IPostStore.GetByIdAsync and reusing the existing ToSummariesAsync helper (wrap the single post in a list) to return a populated PostSummary, or Results.NotFound() if missing/deleted. Add PostApiClient.GetPostAsync(string postId, string? viewerPublicId) calling it. Create MainProject/UI/Pages/PostDetail.razor at [Route("/post/{PostId}")] plus PostDetailCss.razor: loads the post via GetPostAsync, renders it with the existing <PostCard> component (add a [Parameter] bool StartExpanded to PostCard.razor that seeds _showComments = true and calls GetCommentsAsync in OnInitializedAsync when true), includes a BackButton the same way UserProfile.razor does, and shows a 'Post not found' message on 404. Then in Notifications.razor, wrap each notification-row GlassCard in a NavLink to /post/{notification.SubjectPostId} when SubjectPostId is not null.

## Neden
NotificationResponse.SubjectPostId is already sent from the server (NotificationsApiContracts.cs) but Notifications.razor never uses it -- clicking a 'liked your post' or 'commented on your post' notification does nothing today, and there is no way to link directly to a single post at all.
